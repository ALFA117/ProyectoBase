## Mis historias de usuario

> Entre 5 y 7 historias en formato "como [rol] quiero [acción] para [beneficio]", pensadas desde distintos roles o necesidades del producto que el equipo está diseñando. Si escribes menos de 7, borra las líneas que no uses (mínimo 5).

1. Como socio dueño de una unidad, quiero recibir alertas cuando un mantenimiento esté próximo a vencer para programarlo antes de que mi unidad opere fuera de cumplimiento.
2. Como encargado de una flotilla, quiero consultar el estado de mantenimiento de todas las unidades desde un solo lugar para detectar cuáles presentan incumplimientos o servicios pendientes.
3. Como aseguradora, quiero comprobar cuándo y quién registró cada mantenimiento para contar con una trazabilidad clara del origen de la evidencia durante una reclamación.
4. Como inspector de SEMOVI, quiero comprobar desde mi teléfono el estado de una unidad mediante su QR dinámico para realizar una verificación sin depender de documentos físicos.
5. Como responsable de un taller, quiero generar automáticamente un comprobante verificable después de realizar un servicio para entregar al propietario una evidencia que pueda consultar posteriormente.
6. Como socio dueño de una unidad, quiero recuperar rápidamente el expediente de mantenimiento después de un accidente para presentarlo como parte de la documentación de mi reclamación.
7. Como auditor o responsable de cumplimiento, quiero consultar el historial de modificaciones y registros de una unidad para identificar inconsistencias o intentos de alterar la información.
